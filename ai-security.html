OWASP Top 10 for LLM Applications (2026/2025 Framework)

Overview

The OWASP Top 10 for Large Language Model (LLM) Applications is a standard security guide created by the OWASP Gen AI Security Project to identify and prevent critical risks in generative and agentic AI systems.

The latest 2026 update details these primary security vulnerabilities and threats:

LLM01: Prompt Injection

Attackers send malicious direct or indirect inputs to manipulate model behavior, override system instructions, or hijack workflows.

LLM02: Sensitive Information Disclosure

The model inadvertently leaks confidential data, proprietary business information, or PII (Personally Identifiable Information) in its responses.

LLM03: Supply Chain Vulnerabilities

Risks arise from compromised third-party components, pre-trained models, plugins, or external datasets used in the application lifecycle.

LLM04: Data and Model Poisoning

Adversaries corrupt pre-training data, fine-tuning processes, or embedding data to introduce backdoors, biases, or vulnerabilities.

LLM05: Improper Output Handling

Downstream components or interfaces accept model outputs without sufficient validation, sanitization, or encoding, leading to XSS, CSRF, or code execution.

LLM06: Excessive Agency

An LLM-based agent is granted too many permissions, functions, or autonomy, allowing it to take damaging or unauthorized real-world actions.

LLM07: System Prompt Leakage

Internal system prompts, guardrail instructions, or proprietary logic are extracted by users through clever conversational engineering.

LLM08: Vector and Embedding Weaknesses

Flaws in vector databases or embedding pipelines allow unauthorized data access, poisoning, or retrieval manipulation.

LLM09: Misinformation

The model generates false, fabricated, or hallucinated facts that are presented as truth, causing operational or reputational harm.

LLM10: Unbounded Consumption

The application fails to restrict resource usage (such as tokens, memory, or compute cycles), exposing the system to denial-of-service (DoS) or high financial costs.
